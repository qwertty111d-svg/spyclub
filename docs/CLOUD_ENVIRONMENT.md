# Сохранённая настройка облачной среды

С помощью `cloud-environment-onboarding:setup` подготовлена среда для работы
с исходниками Luau, проверки модулей и сборки Roblox Place. GitHub read-доступ
через существующий HTTPS Git proxy проверен; репозиторий исходно был пустым,
с валидной незаполненной веткой. Токены или другие секреты не запрашивались.

В черновике конфигурации подтверждено сохранение двух полей:

- `install_script`: рабочий каталог `/workspace/spyclub`, установка закреплённых
  инструментов через `tools/setup_environment.sh`, активация PATH, компиляция
  и тесты, проверка бинарной целостности, сборка обоих Place.
- `start_skill`: использование существующего checkout без новых worktree,
  активация Luau/Python, необходимые проверки и сборка, разделение облачных
  тестов и проверок Roblox Studio.

Выполнены реальные команды установки, сборки и тестов; повторное выполнение
сохранённого install_script прошло. Luau закреплён на 0.742 / коммите
`8387cfb461b38ce09e37c1e4c2811538ef1bf5cb`. Python zstandard закреплён на 0.25.0;
отдельно проверена установка wheel с проверкой SHA256 из PyPI в локальную venv.

Требования новых секретов, переменных или доменов не добавлялись; существующие
сетевые настройки и список репозиториев сохранены без изменений.

Черновик сохранён, публикация не выполнялась. В настройках среды проверьте
и сохраните изменения, затем опубликуйте среду. Это отдельное действие
от публикации двух сцен игры в Roblox Studio.

В облаке отсутствует Roblox Studio, поэтому среда проверена для редактирования,
компиляции, тестов модулей и сборки. Play Test, устройства, реальные сервисы
Roblox и переходы Place требуют отдельной проверки по `StudioValidation.md`.
