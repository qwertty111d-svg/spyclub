# Настройка облачной среды

В текущей машине проверены установка закреплённого Luau 0.742, Python
zstandard 0.25.0, полный набор headless-тестов и сборка обеих сцен.
Для V135/V96 повторно выполнены полная проверка 308 исходников, сборка
и 6 бинарных тестов; все прошли. Использованы ранее установленные инструменты.
Текущие цели сборки — V142_EXCHANGE/V103_EXCHANGE; результаты текущей проверки
фиксируются в [`EXCHANGE_VALIDATION.md`](../reports/EXCHANGE_VALIDATION.md).
H использует игровую камеру и персонажа в Workspace. В матче стоящая модель
создаётся только на клиенте, а настоящий персонаж сохраняет серверное сиденье.
Headless-проверка не подтверждает вид клуба, кадрирование и качество перехода.

В черновике конфигурации подтверждено сохранение двух полей:

- `install_script`: каталог `/workspace/spyclub`, `tools/setup_environment.sh`,
  активация PATH, `tools/validate.py`, `tools/build_places.py`,
  `tools/test_rbxl_tool.py`.
- `start_skill`: существующий checkout без новых worktree, активация
  сохранённых зависимостей, сборка текущей версии по README/build_places.py,
  различие headless и Studio-проверок. Сохранение подтверждено ответом инструмента.
  Долгоживущие процессы не требуются; Roblox-сервисы запускаются в Studio.

Сетевой список, репозитории и секреты не изменены. Дополнительные credentials
для основной сборки не нужны. GitHub read-доступ проверен через существующий
HTTPS proxy, без извлечения токенов. Оригинальные файлы сохранены.

Также в машине удерживается необязательный независимый rbxl-декодер:
`/workspace/.spy-tools/bin/rbxverify`; официальный Go 1.27.2 проверен по SHA256.
Его исходник — `tools/rbxverify`, зависимости закреплены go.mod/go.sum.

Сохранение черновика подтверждено. Оно не публикует среду и не публикует игру.
В настройках среды нужно проверить и сохранить изменения, затем опубликовать
среду. Восстановление в новой задаче не проверялось.

В Linux нет Roblox Studio. Облако готово для редактирования, компиляции,
исполняемых тестов модулей/контроллеров и сборки. Внешний вид, полноценная
партия, камера в мире, реальные коллизии, звук и сервисы Roblox требуют
проверок из `StudioValidation.md`. Схематичный мир и аватары HTML-канваса
также не подтверждают native-изображение Roblox.
